# 嘉立创 PCB＋贴片装配：先按此文操作

2026-11-06。适用于已完成审核的 RP2350-USB-A 底板 V0.1。电路、布线和固件没有修改。这套资料用于上传、配料和询价；尚未在用户账号中匹配库存、取得工厂DFM或付款。

## 你现在做的第一步

下载 [01-PCB-Gerber-RS274X.zip](01-PCB-Gerber-RS274X.zip)。此 ZIP 可直接上传到 PCB 识别框。需要贴片装配时，再在 SMT 页面上传 [BOM](02-BOM-SMT.csv)和[坐标](03-CPL-SMT.csv)。

在嘉立创网页的 PCB在线下单入口上传该01文件，不必把KiCad工程转换为立创EDA工程。

如果尺寸识别为100.05×80.05mm，这可能来自0.05mm轮廓描边的包围框。向工程说明闭合外形中心线为100×80mm，请按实际外形复核；不要缩放文件或擅自修改尺寸绕过审核。

本板最小设计线宽0.25mm、铜间距0.20mm、过孔钻孔0.30/0.40mm。四个M3安装孔是3.20mm不镀铜孔。01包同时包含PTH和NPTH两个钻孔文件。报价、优惠资格、可选颜色、最小数量与交期以你的当前订单为准，不保证免费。

## 贴片步骤

1. 在该PCB订单关联的SMT流程中，选择手动上传BOM和坐标。
2. BOM上传 **`02-BOM-SMT.csv`**；坐标上传 **`03-CPL-SMT.csv`**。这是53个顶面贴片器件，不包含插件、安装孔或现有RP2350模块。
3. CSV为UTF-8带BOM、英文逗号分隔。字段映射：Comment=型号/描述，Designator=位号，Footprint=封装，Quantity=单板数量；Manufacturer Part为准确原厂型号。**LCSC Part #为空，需在嘉立创订单内逐组匹配，不能把空编号理解为已选料。**
4. 封装和参数逐项核对，尤其U2是宽体SOIC-24，不是TSSOP-24；U3是TSSOP-28，不是QFN。电容必须保留容量、耐压、X7R和0805；电阻为0805、1%。F1、D1-D4保持原厂型号，替料须另核对。
5. 坐标单位mm，全部Top；Y为负数来自KiCad原点在板左上，已保留原生坐标，不要自行取绝对值或镜像。角度归一化为0≤角度<360，尚未验证工厂选定物料的零度约定，须检查工厂贴装预览。
6. 对照[顶层装配图](../carrier/previews/carrier-assembly-top.svg)确认 U2/U3 的 1 脚、芯片型号和焊盘对齐。选择或向工程申请确认生产稿/DFM后再放行生产，以实际订单支持流程为准。
7. **如果你希望收到后完全不焊接，还必须同时安排下一节插件焊接；仅完成这两份CSV的订单会缺端子和排母。**

## 插件也需要焊：另行交给工程确认

把 `04-DIP-quote-only.csv`、`05-assembly-notes.md` 和 `06-module-sockets.svg` 交给嘉立创SMT工程/在线客服询价。嘉立创提供包含插件的装配工艺，但具体连接器库存、两条U1排母以及本单能否代焊仍须确认。

04文件是**询价/后焊清单，不是可与03坐标直接配套上传的自动SMT BOM**。其中14个实际位号J1-J13/JP1对应14个插件；U1额外是两条1×9排母，合计16个物理插件。U1为自定义模块封装，不能把模块整体中心坐标当成任一排母中心。

可直接复制给工程：

> 我需要RP2350底板少量PCBA样板。01是RS-274-X Gerber，02/03是53个顶面SMT器件的BOM和坐标。还请按04/05/06单独确认16个插件（14个接口位＋两条U1排母）的配料和后焊，模块不采购、不焊死，由我最后插入已有开发板。JP1只装针座，不装短路帽。请评估插件方向、排母匹配高度、工艺边/Mark点与测试要求，先报价并提供生产稿/DFM确认方式，不直接放行替料或省略插件。

没有拿到插件装配确认前，不把“SMT匹配完成”当作整板装配齐全。工厂若要求改工艺边、拼板或封装，先回到工程修改并重新验证，再生成对应BOM/坐标。

## 收货后

按原工程 `hardware/carrier/README.md` 验板；先不插模块查短路，再核对电源及插接方向。最后插模块、测试原有手柄桥接与双踏板。JP1保持开路。第三踏板、16键、屏幕和PWM等尚需固件适配，MiGE电机也不能直接接这块底板。

## 文件证据和重建

`verification.json`记录源板SHA256、九层Gerber绘图流比对、53个位号与坐标核对及尚未完成的工厂环节；`checks`为本次原生ERC/DRC证据。`carrier-pos-kicad.csv`为原生坐标留档，不是要上传的03文件。

在项目工具环境中运行 `tools/hardware/export_jlc.ps1` 可重建此套资料。原V0.1工程及通用制板包保持原始字节，不能把后来修改过的BOM/CPL与此PCB包混用。
