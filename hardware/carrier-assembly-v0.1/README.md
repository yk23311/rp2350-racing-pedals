# RP2350 接线底板 V0.1 装配

- [材料清单与焊接手册](carrier-v0.1-assembly-guide.pdf)
- [五张高清分区焊接图](carrier-v0.1-soldering-diagrams.zip)
- [成品渲染图](carrier-v0.1-render.png)

手册采用 4.7kΩ 分压装配方案。R1–R8 的电阻按上下臂成对更换，保持 1:1 分压。只装双踏板时，R1–R4 各用一颗 4.7kΩ、1% 的 0805 电阻。嘉立创文件夹的 SMT BOM 对应原版 10kΩ 分压方案，下单时按所选装配方案核对。

装板前按手册核对位号、插座方向和电源。底板的 KiCad 源文件、接口与电源说明见[底板说明](../carrier/README.md)。
