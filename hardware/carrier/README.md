# RP2350-USB-A 可扩展接线底板 V0.1

本板用于固定现有微雪 RP2350-USB-A 并集中接线。100×80mm、双层、1.6mm，四个 M3 安装孔；保留开发板 Type-C 和 USB-A。它是待制造/上电验证的工程样板，不是伺服电机驱动器。

用户暂定直驱电机 **MiGE 90ST-M02430**，驱动器尚未选定。电机资料与接口约束见 [motor-notes.md](motor-notes.md)。电机动力端及电机编码器不能直接接本底板。

## 文件入口

- `carrier.kicad_pro`：KiCad 工程入口。
- `carrier.kicad_sch` / `carrier.kicad_pcb`：可编辑原理图与 PCB。
- `Carrier.kicad_sym` / `Carrier.pretty`：本地模块符号与正确排针封装；不是 Pico 标准封装。
- `bom.csv`：逐位器件表，包含型号、封装、用途。U1 是模块加两条 1×9 排母的装配体。
- `previews/`：原理图 PDF/PNG、PCB 和 3D 预览。
- `reports/`：ERC、DRC、原生网表、布线交换文件和检查证据。
- `fabrication/`：检查通过后导出的样板 Gerber/钻孔；制造参数和最终检查结论以阶段报告为准。
- `circuit-notes.md`：器件资料、电气计算和限制。

KiCad 10 打开工程。3D 模块/USB 外形为尺寸示意代理，**高度未经实物测量，不能直接用来定制机壳**；模块孔位和板平面尺寸来自微雪官方图。

## 样板加工参数

双层 FR-4、板厚1.6mm，闭合外形中心线100×80mm；普通1oz铜厚与常规阻焊即可作为样板加工起点。最小设计线宽0.25mm、铜间距0.20mm；信号过孔钻孔0.30mm，电源过孔0.40mm；四个安装孔3.20mm且不镀铜。最终下单前由制板厂确认其工艺能力，PCB颜色/表面处理可自行选择。

PTH和NPTH钻孔均需提交。Gerber Job显示的100.05×80.05外接尺寸包含0.05mm轮廓描边，实际闭合外形中心线为100×80mm。导出焊膏层供需要时参考，不代表本项目已准备自动SMT采购/贴片订单。U1模块/排母、外部排针和接线端子需按BOM装配。

| J2 BRAKE | 1=5V，2=GND，3=OUT → GP27 | 双踏板刹车 |
| J3 CLUTCH | 1=5V，2=GND，3=OUT → GP28 | 待扩展 |
| J4 AUX | 1=5V，2=GND，3=OUT → GP29 | 待扩展 |
| J5 按键01–08 | 1..8=按钮，9=公共GND，按钮接地闭合 | 待I²C适配 |
| J6 按键09–16 | 1..8=按钮，9=公共GND | 待I²C适配 |

| J8 I²C屏幕/模块 | 1=3V3，2=GND，3=SDA，4=SCL | 待适配 |
| J9/J10 震动控制 | 1=3V3逻辑参考，2=GND，3=PWM | 待适配；不能接马达 |

| J13 备用PWM | 1=3V3，2=GND，3=PWM2，4=PWM3 | 待适配 |

### J11：不是电机或伺服驱动器标准插头

| 奇数针 | 信号 | 偶数针 | 信号 |
|---:|---|---:|---|
| 1 | 3V3逻辑电源 | 2 | GND |
| 3 | SCK / GP6 | 4 | GND |
| 5 | MOSI / GP7 | 6 | MISO / GP4 |
| 7 | CS / GP5 | 8 | EN / GP8（普通控制，默认LOW） |
| 9 | IRQ_N / GP9（3.3V开漏） | 10 | GND |

所有信号仅为板内 3.3V，供未来通信/隔离子板使用；不是 CAN_H/L、RS485 A/B、±10V 扭矩端子，也不是电机 U/V/W。对应子板须在伺服驱动器型号和指令接口确定后设计。EN 不是安全认证 STO。

## 电源和输出默认状态

传感器 5V 来自模块 USB VSYS，经 F1 支路 PTC；3.3V 来自模块稳压。板上没有电机电源入口。现有固件对主机声明整机 100mA，需计入模块、USB接收器、逻辑、传感器及屏幕；扩展口数量不代表主机允许的电流。

四路模拟输入均为 10k/10k + 100nF，只按 0–5V 模拟信号设计。不得独立给外部传感器上电后向断电底板送信号。PTC/TVS不等于完整过压或断电反灌保护，详见电路说明。

PCA9555=0x20，PCA9685=0x40，PCA9685上电还响应0x70；I²C只接3.3V逻辑。PWM芯片所有通道共用频率，范围约24–1526Hz；这两路仅用于兼容该范围的外部震动驱动，不作为直驱伺服扭矩接口。

## 建议装配与验证顺序

1. 按BOM装配电阻、电容、TVS、PTC和两颗扩展芯片；核对U2/U3的1脚与封装方向。暂不装JP1短路帽。
2. 底板U1位置装两条1×9、2.54mm排母；开发板装向下排针，Type-C朝板左侧，USB-A朝接收器净空区。不要反插。
3. 插模块前检查焊接短路、电源与地，再核对5V/3.3V供电。首次上电不接踏板、屏幕、外部驱动或电机，使用限流电源/合适检测工具完成板级检查。
4. 插模块后先验证原有USB手柄桥接；之后逐路接入已有踏板、重新校准，核对USB总功耗和端子供电压降。
5. I²C扫描、16键、编码器、第三踏板与PWM需要后续固件；不能以旧GUI没有显示就判断接线损坏。JP1保持开路，直到新固件与外部低压驱动测试就绪。
6. 直驱电机和驱动器保持独立。按选型资料另做通信/隔离、位置反馈、硬件急停及卸扭矩验证，再接J11子板。

本次没有制造、焊接、上电或电机运行证据。原理图/PCB检查通过只表示其规则覆盖范围内没有违规，不能替代实物验证。

## 编辑和重建

可直接在KiCad10中编辑原理图/PCB并进行常规更新网表、重新布线和检查。`design.json`与生成器提供本次设计的可重建规范；修改模型后，需重新生成原理图、导出原生网表，再布线，不能沿用与新电路不一致的旧SES。

项目内已准备工具时，`tools/hardware/export_carrier.ps1`默认检查并导出当前板图；`-Rebuild`复现本次布局并导入保存的SES；`-Route`重新执行离线布线再导入。完整工具来源和环境见 `hardware/reference/cad-toolchain.md`。大型CAD工具和官方标准库未打进工程源码包；普通KiCad10安装也能打开工程和本地模块库。
