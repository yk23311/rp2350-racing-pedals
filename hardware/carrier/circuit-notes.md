# 电路设计依据与边界

工程样板 V0.1，2026-11-06。`design.json` 是引脚与网络连接规范；原理图由 `tools/hardware/build_schematic.py` 生成。生成器通常只读取模型，不覆盖 PCB 的 placement 数据；`--init-model` 仅用于从零初始化。

## 模块与电源

U1 为现有微雪 RP2350-USB-A 模块，两排 1×9 排母，不是 Pico 封装。模块输出的 VSYS USB 5V 通过 F1 供应四个传感器；模块 3V3 为逻辑、显示器、编码器和子板逻辑供电。无外部电机电源接点，也不允许向这些供电脚反向灌电。

F1 使用 Bourns MF-NSMF025X-2（0.25A hold、0.50A trip、16V、1206）。厂家 R1max=2.3Ω，50mA 时仅按该电阻计算压降最多约 0.115V，另须加上线缆、USB 和模块路径压降；仍不能承诺端子恰好为 5.00V。PTC 是短路缓解措施，动作受温度及过流大小影响，不是精准限流器，也不能限制 USB 总电流在描述符声明范围内。C8/C9 为支路 4.7µF/100nF，C5/C6 分别紧靠 U2/U3，C7 为 3V3 的 4.7µF。

**现有固件两个 USB 描述符 bMaxPower=50，即整个 USB 设备声明 100mA。** 此预算包含 RP2350 模块、USB-A 无线接收器、底板逻辑、传感器、屏幕和其他扩展，不能把 100mA 当作传感器剩余电流。四传感器 50mA 只能作为待测例子，不是可用电流承诺。连接扩展前必须测量基线和各负载、核对传感器最低供电电压；超预算时需要另行设计供电/固件申报方案，本次不改描述符，也不增加外部电源入口。F1 的 0.25A 额定值不代表主机已授权该电流。

## 四路模拟输入

J1/J2/J3/J4 均为 1=5V_SENSOR、2=GND、3=OUT；分别为油门 GP26、刹车 GP27、第三踏板 GP28、辅助 GP29。只接受相对 GND 的 0–5V 模拟输出，不能直接接 PWM、数字、负电压或汽车电源传感器。

每路固定 10kΩ/10kΩ、1% 分压，输出端 100nF。理想增益 0.5，5V 输入得到 2.5V；1% 电阻最坏比例下约 2.525V。戴维南电阻约 5kΩ，时间常数约 0.5ms，截止频率约 318Hz。ADC 采样时间、多通道切换建立时间和源阻抗仍须在固件中验证。无绕过分压的跳线。

D1–D4 是 PESD5V0S1BA 双向 5V ESD TVS，接在 OUT 与 GND 之间，靠近端子。厂家给出的钳位电压可高于 ADC 绝对额定值；TVS + 10k + RC 仅作为 ESD 缓解，**不宣称整机已通过 IEC ESD，也不保证持续过压存活**。本板没有电源关闭隔离开关：即使 10k 限制注入电流，断电时外部信号仍可能通过 MCU 内部结构反向供电。传感器必须由本板支路供电；断电前停止外部驱动，禁止独立上电传感器或带电插拔。若需独立供电/车载长线，下一版必须增加经验证的断电保护前端。

## I²C、按键和屏幕

GP0=SDA、GP1=SCL，R25/R26 各 4.7kΩ 上拉至 3V3。U2 PCA9555D,118（SO24）地址固定 0x20；U3 PCA9685PW,118（TSSOP28）地址固定 0x40。PCA9685 上电还响应 All Call 0x70；不能把 0x70 分配给新屏幕/传感器。常见 0x3C/0x3D 屏幕仍必须核实实际模块。

J5 pins1..8 是 BTN01..08，J6 pins1..8 是 BTN09..16，两者 pin9=GND。每路各有 10kΩ 上拉，按钮闭合到 GND。U2 上电为输入；INT 引脚有明确 NC，因为 GPIO 已全分配，后续固件轮询读取全部 16 路并消抖。没有借用按钮脚控制 PWM OE。

J8 为 1=3V3、2=GND、3=SDA、4=SCL。屏幕只能用 3.3V 逻辑；检查屏幕板自带上拉，不能把总线上拉到 5V。初始总线使用 100kHz、短线，确认电容/上升沿后再提高速度，PCA9555 上限为 400kHz。

## 编码器、模式、震动信号

J7 为 1=3V3、2=GND、3=A(GP2)、4=B(GP3)，A/B 各有 10kΩ 上拉。适用机械接点、3.3V 输出或开漏输出；不支持 5V 推挽、RS422 差分或电机编码器直接连接。

J12 为 1=GP10 MODE_N、2=GND，R37 为外部上拉。现有固件 MODE 默认 GP14 不在模块排针，GP10 仅为后续适配预留，本次不修改固件。

J9/J10 为 1=3V3 逻辑参考/小电流逻辑供电、2=GND、3=PWM。它们是控制外部马达驱动的低压信号，不能接马达。PWM0/1 各串联 330Ω，输出各有 10kΩ 下拉。U3 上电输出 LOW；OE 由 R36 拉高，JP1 默认不装短路帽。短接 JP1 才允许 PWM 输出（MODE2 保持 OUTNE=00 时 OE 高强制 LOW）。OE 的作用受 MODE2 配置影响，固件必须保留安全的 OUTNE 设置；不是安全认证的硬件关断。

U3 EXTCLK 接地使用内部振荡器。J13 为 1=3V3、2=GND、3=PWM2、4=PWM3，其余 12 路 PWM 输出明确 NC。PCA9685 所有通道共享约 24–1526Hz 频率范围，不能事先承诺兼容要求 20kHz PWM 的驱动器。仅适用经核实能接受该范围及 3.3V 逻辑的外部驱动。初始化先写全关断、MODE2 和频率，再进行软件 PWM 测试，最后手动装 JP1。通信中断后不会自动归零，需要外部驱动自身 watchdog/禁用机制；本板没有独立看门狗。

## SPI 接口子板槽

J11 是 2×5、2.54mm，顶视奇偶列编号；按针号连接：1=3V3、2=GND、3=SCK(GP6)、4=GND、5=MOSI(GP7)、6=MISO(GP4)、7=CS(GP5)、8=EN、9=IRQ_N(GP9)、10=GND。EN 来自 GP8，串联 330Ω，槽端 10kΩ 下拉，默认 LOW。IRQ_N 仅接受 3.3V 开漏故障/中断输出，板上 10kΩ 上拉。接口各信号不具备板外长线浪涌/隔离保护。

EN 是普通逻辑控制，**不是 STO/安全急停**。本次不指定伺服通信协议，不包含逆变桥、母线、隔离接口、功率器件、STO 或电机接线。驱动器未选型；XInput 双马达震动不能直接当作方向盘扭矩。本次原理图/PCB 不使当前固件获得 HID PID 直驱力反馈能力。
