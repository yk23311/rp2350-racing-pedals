# 04 板级固件：步骤与交接

日期：2026-10-30；构建验证更新：2026-10-31。

## 步骤报告

1. 使用SDK官方 `waveshare_rp2350_usb_a` 板型，ARM-S单核。
2. ADC0/1对应GP26/27；通道切换后丢弃首个转换。GP14为可选低有效模式按键。
3. 手柄与键盘使用独立HID接口，CDC占两个接口，合计4接口5端点。固定枚举；USB只由主循环调用。
4. 先写USB描述符/中立屏障测试并观察失败，再实现并通过：总长度125字节、端点唯一、轴32bit/键盘64bit输入、无符号65535上限、等待两个中立报告完成、旧一代在途报告不能解除新屏障。
5. 由SDK原始链接脚本生成项目副本，将FLASH长度缩到0x1FE000；物理Flash大小仍为2MiB。配置双槽通过SDK安全执行API写入。
6. 依赖隔离下载到 `deps/`，不修改用户原有 `.pico-sdk`。构建结果和最终固件哈希在总交接中登记。

## 交接报告

已用Arm GNU 14.3.1交叉构建成功，94个步骤通过，产物归集到`dist/`；见`logs/firmware-success.txt`。中文路径下链接器无法找到标准库，已用临时SUBST盘符解决并写入构建脚本；映射结束后移除。构建成功不代表已经上板。使用Type-C，USB-A不启用。模式变化、校准和参数更新清空滤波，等待中立与回零；挂起/恢复重置USB状态。系统掉线/重连由USB栈处理，未做实机USB抓包。

ELF验证：`__flash_binary_start=0x10000000`、`__flash_binary_end=0x10009708`，配置区从`0x101FE000`开始；`write_slot=0x20000110`、`flash_range_erase=0x20000378`、`flash_range_program=0x20000424`均位于SRAM。程序Flash跨度38664字节，UF2末块也不会触及配置区。

编译参数与步骤由 `tools/build_firmware.ps1` 固定。`.uf2`来自受测试的RP2350 ARM-S打包器，仅支持本工程地址与保留区，不提供签名、加密或自动烧录。

上板前仍需电气测量；PC逻辑/Flash模拟测试不验证ADC电压、ADC稳定时间、实际USB时序或Flash断电耐受。
