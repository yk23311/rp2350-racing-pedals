# 03 配置及CDC协议：步骤与交接

日期：2026-10-30。状态：PC验证通过，真实串口待验收。

## 步骤报告

1. 先写配置记录与控制台测试；最小实现下`config_records`、`console_protocol`失败。
2. 实现40字节显式小端记录、CRC32、双槽选择、序号回绕；避免结构体padding或bool ABI进入存储格式。
3. 实现有界行输入、严格整数与参数范围校验、原子RAM更新、校准状态约束、SAVE与DEFAULTS。
4. 测试逐字节翻转、所有截断长度、两槽损坏/回退、超长行恢复、数字溢出和命令尾随字段，均通过。
5. 实际`firmware/storage.c`在Flash模拟器中运行：40个写入截断位置恢复旧配置，安全执行失败不破坏旧槽，重复保存相同配置不擦写，测试通过。
6. 独立审查指出CDC断开后残留TX：加入DTR断开清理及32hex随机token的PING。主机测试包含完整旧响应、无换行在途残段、同步超时。

## 交接报告

完整命令和单位见 `docs/protocol.md`。配置只经 `pedal_apply` 校验，GET可输出JSON；板端不提供任意JSON导入。SAVE成功才表示写入/读回校验完成，错误不能当成功。上位机仅在建立连接时使用PING同步，正常请求严格一发一收；超时后应重连。

Flash模型验证记录的事务恢复，不代表真实供电下降波形下已验收。上板需执行断电、CDC积压重连、保存期间USB表现验证。
