## 用户实际结果与根因证据

1. 原始KiCad10文件在EDA Pro4.1.97能显示原理图和PCB，但初始DRC为36项：27项过孔默认最小0.5mm规则、8项铜区与禁布区重叠、1项网表差异。
2. 将最小孔径恢复为原设计0.30mm后，27项消失。执行铺铜重建后画面铜线/铺铜消失，DRC只显示网表差异；应用过网表的副本出现221项断连。由此确认“可见布局”与“导入网络有效”需要分别验证，不能仅据DRC条数减少放行。
3. 用户导出`eda-import-diff.csv`到项目根目录。它实际为UTF-16制表符表格，653项操作：65删除属性、207新增属性、159修改属性、221修改网络、1新增设计规则。221项网络的导入前值全部为`-`，其中49个GND相关引脚在原理图侧被命名为`power_PWR_FLAG`。
4. 还有15项实际值差异：C7/C8在PCB侧为100nF而应为4.7µF，R25/R26为10k而应为4.7k，R30/R32/R34为10k而应为330Ω，以及8项连接器描述。原始KiCad中这些值正确，差异出现在转换/共享封装属性回填后。
5. 检查原始板文件：KiCad10使用`(net "name")`，无旧式索引网络表；共234处pad、581处segment、27处via、2处铜区网络关联。结合报告，网络表示的导入兼容性是明确需要修复的环节；具体LCEDA内部实现未作逆向或改动。

## 修复范围

只在`hardware/lceda-compat/`生成副本。具名网络写成旧式索引网络表和对象索引；Reference/Value使用兼容fp_text表达；去除ERC专用PWR_FLAG和对应单独支线/标签，并把模块GND的ERC类型改为power_out以保留原供电声明。文件版本不伪改，电路拓扑、布局和物理铜线保持不变。原始`hardware/carrier`、原Gerber包和固件未变。
