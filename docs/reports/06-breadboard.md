# 06 面包板图：步骤与交接

日期：2026-10-31。用户要求按现有条件绘制面包板接线图。

## 步骤报告

1. 使用确定坐标的程序绘图，固定孔位，生成`docs/images/breadboard-dual-pedals.png`。
2. 两个独立通道各用10kΩ上电阻、10kΩ下电阻、100nF无极性陶瓷电容。
3. 每个孔只安排一个元件脚或跳线端点；电源轨桥接、传感器供电和开发板共地分别占不同孔。
4. 查看PNG，修正孔位文字遮挡、箭头字体和元件标记；逐项核对孔位表、分压节点与地线。

## 交接报告

详见`docs/breadboard-wiring.md`。图中采用独立5V传感器电源，开发板Type-C连接电脑，并与传感器电源共地。开发板为逻辑端子示意，不是实物针脚位置图。

颜色与信号类型仍是未核实假设：红=5V、黑=GND、白/黄=0～5V模拟OUT。此图不证明实际踏板匹配这些假设；未进行实物搭建、测量或上板验证。
