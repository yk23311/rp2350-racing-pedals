# 05 上位机与资料：步骤及交接

日期：2026-10-30；环境与界面验证更新：2026-10-31。状态：CLI协议自动测试通过；GUI已通过隐藏窗口构建/尺寸检查，实际设备交互待验收。

## 步骤报告

1. Python CLI先写串口契约失败测试，再实现GET、SET、校准、模式、SAVE、JSON导出和CSV轮询记录。
2. 验证超时、错误响应、JSON损坏、非ASCII、超长及换行注入、协议版本、参数范围；同步覆盖旧响应和在途残段。
3. 加入Tkinter滑条UI，串口操作在单个工作线程，主线程200ms刷新；只在“应用参数”更新RAM，“保存到Flash”才持久化。
4. 加入受测试的BIN→UF2转换；检查family、块头、地址、重建一致性，以及不能覆盖配置保留区。
5. 编写README、硬件测量表、协议文档、V0–V9验收与恢复操作。

## 交接报告

启动GUI：`powershell -ExecutionPolicy Bypass -File tools/start_gui.ps1`。项目`.venv`已安装pyserial3.5；串口由用户在设备管理器确认，不自动扫描并发送命令。CLI导出和日志以新文件方式创建，防止覆盖既有记录。

隐藏窗口构建发现原800×520窗口小于763×548的内容需求；已补充失败回归测试并修正为800×600，同时按实际内容设置最小尺寸，避免DPI/字体影响导致底部裁切。未打开串口，未进行真机GUI操作。

两踏板每轴先全松开BEGIN，再全踩保持END；返回OK后松开双踏板，等待使能及中立，再显式SAVE。2026-10-31修正：设备完整返回ERR时GUI保留连接，显示可重试提示；真正通信超时、损坏响应或IO异常才关闭串口。校准会话仍在板端，重连后GET可确认并CANCEL，不会自动保存。详见`07-calibration-connection.md`。

GUI未与实际板卡交互；一小时CSV命令仅提供执行步骤，没有声称运行过一小时老化。扩展的屏幕、方向盘、触觉反馈和宏未实现。
