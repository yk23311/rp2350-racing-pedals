# 硬件接入与测量交接

## 已确认板级信息

| 用途 | 接口/引脚 | 状态 |
|---|---|---|
| PC HID + CDC | Type-C / RP2350原生USB | 官方原理图确认 |
| 油门输入 | GP26 / ADC0 | 本固件分配；接线尚未验收 |
| 刹车输入 | GP27 / ADC1 | 本固件分配；接线尚未验收 |
| 可选模式按键 | GP14对GND，内部上拉 | 长按1.5s切换，30ms消抖；默认不接亦可 |
| USB-A | GP12 D+、GP13 D−，PIO | 本固件未启用 |
| 配置存储 | 2MiB外置W25Q16末尾8KiB | 与程序链接区隔离 |

按板上 GP 丝印接线，不套用 Pico 2 的排针编号。BOOT用于启动下载，不作为普通模式键。

## 接线前需要的实际数据

用户目前只确认“双踏板，5V供电”。对每路填写：

| 项目 | 油门 | 刹车 |
|---|---|---|
| 传感器型号或标记 | 未提供 | 未提供 |
| VCC / GND / OUT线序 | 未确认 | 未确认 |
| 输出类型（模拟电压/PWM/数字） | 未确认 | 未确认 |
| 全松开 OUT对GND 电压 | 未测 | 未测 |
| 踩到底 OUT对GND 电压 | 未测 | 未测 |
| 全行程最小/最大值 | 未测 | 未测 |
| 供电最大电压和电流 | 未测 | 未测 |
| 现有内部调理/分压 | 未确认 | 未确认 |

先使用已确认线序和额定供电的原设备，或限流5V台架电源测量；此时信号线不连接开发板。若输出为PWM、开漏数字或其他接口，不能直接按模拟踏板接入，应调整HAL/电路设计。颜色不能代替线序确认。

## 模拟输出确认后的调理原则

```text
传感器OUT ── R上 ──┬── ADC GP26/GP27
                   ├── R下 ── GND
                   └── C ──── GND
传感器GND ───────────── 模拟公共地
```

`Vadc = Vout × R下/(R上+R下)`。按照实际最大输出、USB供电公差、阻值公差和板上实测3V3/ADC参考留余量；正常工作电压不可把器件绝对最大额定值当目标。RC截止频率近似 `1/(2π(R上∥R下)C)`，还要考虑传感器源阻抗和ADC采样建立时间。

仅供计算的候选：**如果**确认是低阻模拟输出、最坏不超过5.25V，R上12kΩ/R下15kΩ、各1%、C100nF时，名义比例0.556，最坏高比例约0.5605，对应约2.943V；名义RC约0.667ms，截止约239Hz。此值未通过传感器负载、噪声、瞬态和板上测试，不是最终BOM。若已经是合规3.3V模拟信号，额外分压可能只损失量程。

电容靠近ADC引脚；共地回流避开电机/USB大电流路径；供电去耦按传感器数据手册。上电/断电时不能让已通电传感器通过OUT反向给未上电MCU供电。需要外部过压/ESD保护时，核算钳位电流和回灌路径，RC本身不等于过压保护。

“从板子取电”不等于电气隔离。首版只接小信号传感器，先核对整板+传感器低于声明的100mA USB功耗；未来电机用独立设计的供电和驱动，不能从GPIO直接带负载。

## 机械与上板顺序

先确认机械限位、弹簧和线束固定、防滑底座；调理电路离板测量通过后，断电接公共地和ADC信号。第一次烧录可以完全不接传感器，只验证USB和CDC；其后按 `validation.md` 逐级接入。未校准中立只是软件保护，不能保护ADC免受过压。
