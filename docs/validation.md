## 建议验收阈值（待实测确认，不是当前测量结果）

- 回零输出保持0，全行程可到65535，无自发按键。
- 按键30ms消抖、稳定按下1500ms只切一次；持续按住不得重复切换。
- 1ms采样/报告为调度目标。用GPIO标记+逻辑分析仪或USB抓包测端到端延迟、最大间隔；主循环+USB负载下记录峰值，不只平均值。SAVE时允许专门测量的中立停顿。
- 1h测试至少每10分钟记录静止30s原始ADC分布、温度、最大/最小及均值。漂移是否低于释放死区应基于校准跨度计算，不凭感觉判定。
- 输入断线若落在0–4095范围内，当前固件不保证识别。用已知安全的信号源模拟故障，之后决定是否加硬件诊断或限幅异常策略。

## 可复现命令

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_host.ps1
powershell -ExecutionPolicy Bypass -File tools/build_firmware.ps1
python tools/pedalctl.py --port COM5 monitor --seconds 3600 --interval 0.1 --output aging.csv
```

CSV仅为10Hz主机观测，不是1kHz全部样本。老化报告另记录板卡版本、传感器、电阻电容、环境温度、固件SHA256、游戏和驱动版本，才能比较多次结果。

## 恢复操作

电压异常立即停止接入，保留测量数据；配置无效时默认未校准；需清配置可执行DEFAULTS、松开等待中立、SAVE。固件不能启动时按BOOT重新连接Type-C恢复下载。不要用整片擦除作为日常调参方式。
