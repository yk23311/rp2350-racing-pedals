# 驾驶控制中心：使用步骤

## 1. 打开界面

双击项目根目录 **启动调参GUI.bat**。新版默认打开Qt控制中心，自动发现本项目板卡的串口；只有一台匹配设备时自动连接。多台时在顶部选择端口/序列号后连接，不会向其他串口设备发送探测命令。

没有硬件时可以预览界面：

```powershell
powershell -ExecutionPolicy Bypass -File tools/start_gui.ps1 -Demo
```

演示模式有明确标记，所有数据是模拟数据，不能应用或保存到开发板。旧Tk界面仍可通过`tools/start_gui.ps1 -Legacy`启动。

## 2. 升级固件以使用手柄功能

旧固件可继续使用踏板调参，但手柄状态、曲线与映射会显示不支持。使用这些功能需要新版 **0.4.0-control-center**：

1. 先用旧GUI导出或记录当前踏板端点、死区、曲线，保留备份。
2. 关闭GUI，断开板卡Type-C；按住BOOT连接电脑，释放BOOT。
3. 把`dist/host/pedals-host.uf2`复制到出现的BOOTSEL磁盘，等待自动重启。
4. Type-C接电脑，真实2.4G接收器插开发板USB-A，踏板仍接GP26/GP27。接收器不要另插电脑。
5. 松开踏板、手柄扳机和按键，摇杆回中；重新打开控制中心。

**本次构建未烧录、未实机验收。** 旧PDL1校准会读取到内存并保留；只有显式保存时才写PDL2新格式。保存新格式后旧固件不认识PDL2，降级可能回到较旧校准或默认值，不能承诺无损降级。不要整片擦除Flash。

## 3. 看懂总览

- 左侧两个大仪表：踏板处理后的16位输出百分比；下方显示ADC原始/滤波值。
- 右侧观察数据层：**原始输入**是接收器报告；**处理后**是手柄曲线和映射结果；**最终输出**包含踏板MAX合并，是开发板准备发送的状态，并非Windows额外回读。
- 按住手柄按键会亮起；双摇杆二维点和LT/RT条随操作变化。
- Host状态/报告年龄/超时计数区分“接收器有报告”与未知无线状态。接收器可能在手柄关机时仍发中立帧，不能仅靠中立帧证明无线手柄在线。
- 串口断开或Host原始数据过期时不把旧读数当实时。没有接收器且从未接入时，独立踏板的最终输出仍能显示。

## 4. 调踏板

1. 进入“踏板调校”，全松开所选踏板，点击①开始。
2. 踩到底保持，点击②完成。若行程不足，保持或重新校准，完整ERR不会强制断开串口。
3. 松开两踏板、手柄扳机和按钮，等待回零。
4. 修改触发阈值、释放阈值、γ和滤波窗口。释放必须小于触发；默认触发3%、释放1%。
5. 曲线显示启用后的响应，标出触发/释放迟滞区，游标是当前输入位置。参数修改先预览，不立即改变游戏输入。

γ=1接近线性，γ增大使前段更平缓。踏板曲线作用于踏板，真实手柄扳机曲线独立。当前仍用MAX：最终每个扳机取两路处理结果较大值，所以手柄扳机按住时松开踏板不会抵消它。

## 5. 调摇杆与扳机

“摇杆与扳机”页提供左右摇杆中心死区、γ、X/Y反转，左右扳机起始死区、γ。摇杆按半径处理并保留方向；默认零死区/γ1不改变原始轴值。

调好点击“应用到设备”；释放实体输入、摇杆回中后恢复输出。关闭GUI后，处理仍由开发板执行，不依赖电脑映射器。

## 6. 按键映射

“按键映射”中每个来源可选择另一个手柄按钮、单个键盘按键或禁用。支持14个标准数字按键；没有鼠标或组合宏。按下时源行高亮，原始与最终状态可在总览对比。

按住源键会保持目标，松开释放；多个源映射同一目标时，全部松开才释放。映射是替换而非叠加原按键。键盘最多同时6个普通键，Ctrl/Shift/Alt/Win独立；超限显示rollover，松开后恢复。

更改映射、模式、校准或断连时先释放旧手柄/键盘输出；按住期间不会直接继承到新映射。键盘W/S模式作为旧功能保留，模式只在RAM中，重启回手柄模式。

## 7. 应用与保存

- **有未应用修改**：只是本地预览，游戏仍用已应用参数。
- **参数已应用到RAM**：板卡已确认，尚未持久化。
- **Flash已保存**：收到SAVE成功并刷新状态后才显示。
- **撤销修改**：恢复设备当前已应用值，不是恢复出厂，也不写Flash。

校准也会改变待保存状态。保存前需结束校准、松开两踏板及所有真实手柄按钮/扳机，并等待中立屏障完成；摇杆轻微漂移不影响SAVE。若暂时拒绝，释放输入等待后重试。

断线重连或切换设备会重新读取参数并清理未应用草稿，避免把另一台设备的旧值覆盖过去。重连不会自动重放应用、校准、SAVE。

## 验证与故障排查

新GUI运行时不会安装驱动或模拟输入。若手柄功能灰色，检查是否烧录0.4.0普通桥接固件；普通版不刷Host日志是正常行为。诊断版仅排查时使用，不作为可靠调参基线。

实机需逐项检查：同一槽位转向+油门、转向+刹车、键盘按下/释放、关闭GUI后仍生效、SAVE重启保留、接收器断连与回连。然后由用户关闭Steam Input并做FH6验收。

开发验证：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_host.ps1
powershell -ExecutionPolicy Bypass -File tools/start_gui.ps1 -Check
powershell -ExecutionPolicy Bypass -File tools/build_firmware.ps1 -UsbMode host
```

GUI依赖已装在项目`.venv`；重建环境时使用`.venv\Scripts\python.exe -m pip install -r tools/requirements.txt`。首次只需安装固定版本PySide6-Essentials和pyserial，无需Qt商业工具、PyQt或浏览器服务。
