# RP2350 双踏板首版设计

日期：2026-10-30。用户已授权“审核后开始实施，每一步形成步骤报告和交接报告”。

## 审核结论及范围

四层结构可行，按审核修正后实施。硬件已知为微雪 RP2350-USB-A、两个踏板、传感器 5V 供电；信号类型、输出范围、线序及电流未知。首版负责双踏板固件、电脑端调参工具及可复现测试。屏幕型号未定，屏幕菜单、方向盘、震动反馈、复杂宏均为后续独立阶段，不纳入首版验收。

选型比较：Pico SDK + TinyUSB 可共用 PC 测试的纯 C 核心、直接控制 USB 和 Flash，采用此方案；Arduino 生态启动容易但增加板包依赖；MicroPython 适合采样原型，但本项目的复合 USB 与持久化控制优先使用 C SDK。

## 分层及数据流

硬件信号调理 → HAL 定时读取 ADC → 核心短窗口平均 → 端点映射/反向 → 迟滞死区 → 幂曲线 → USB 报告。

- 板型：SDK `waveshare_rp2350_usb_a`，首版单核 ARM Cortex-M33。
- 两个轴：0 油门、1 刹车；计划 GP26/ADC0、GP27/ADC1，接线前核对板卡及实际信号。
- 外接可选模式按键：GP14 对地，内部上拉，30 ms 消抖，长按 1500 ms 切换一次，松开后允许下次切换。BOOT 不作为普通模式键。
- 采样周期目标 1 ms，每轴平均窗口 1–8，默认 4。硬件实际周期和噪声须上板测量。
- HID：两个 unsigned 16-bit 轴 X/Y，8-byte boot keyboard 报告，两个独立 HID 接口 + 一个 CDC 功能，固定枚举。
- 模式切换、校准及配置更新先输出中立；USB 层待两个中立报告完成后才允许正常报告。每次切换要求踏板回零后重新使能，避免粘键和带油门切换。
- 默认 joystick；keyboard 模式油门 W、刹车 S，允许同时按下。双踏板不生成 A/D。

## 核心行为

端点保存 `released`、`pressed`，以其大小自动判断反向。正常运行冻结校准。显式 BEGIN 保存全松开值并开始跟踪 min/max，END 在踩到底时取端点，最小有效跨度 128 ADC counts；失败保留原配置，CANCEL 丢弃会话。校准期间两轴和键盘中立，默认未校准亦中立。

ADC 输入范围 0–4095；异常范围立即中立并解除使能。仅软件无法可靠识别所有悬空或断线，需结合电气诊断。迟滞用归一化行程：默认 3% 激活、1% 释放，在二者之间保留活动态；激活后将 1%–100% 重映射至 0–65535，曲线在死区之后应用。gamma 可调 1.00–4.00，油门默认 1.00，刹车默认 2.00。整数配置单位为万分比/百分之一，拒绝 NaN、非法端点、越界及不合法迟滞关系。

## 配置与可靠性

CDC 使用有界 ASCII 行协议（最大 127 字符，超长整行拒绝），响应 OK/ERR。GET 返回 JSON 供电脑保存和检查；SET 在 RAM 原子校验后生效，SAVE 才写 Flash。避免自建完整嵌入式 JSON 解析器；电脑 JSON 文件与板端固定格式记录职责分开。

板端配置记录：版本、序号、显式小端字段、CRC32。末尾两个 4 KiB 扇区交替写入，读取时选择最新有效记录，损坏回退另一槽；没有有效记录使用未校准默认值。保留旧槽，写后读回验证。通过链接区域限制排除末尾 8 KiB；显式调用 SDK `flash_safe_execute`，首版第二核心不启动。保存仅允许运行输出中立且无校准，写入期间暂停采样，恢复时清空滤波并重新使能；Flash 写入可能导致短暂 USB 停顿，必须实测。

## 测试和交接

PC 自动测试覆盖映射两种方向、满量程、短窗口启动、迟滞、曲线、校准状态、非法参数、CRC/序号回绕/掉电记录、模式释放和协议解析。USB 描述符做结构测试；固件交叉构建与硬件 USB 枚举分开记录。

每阶段报告包含输入、实际变更、命令、结果、未完成项、接手步骤。硬件验收必须记录信号电压、joy.cpl、键盘释放、断电保存、一小时漂移、目标游戏兼容性。未执行的检查明确写“未执行”，不能以 PC 测试代替。

## 外部约束

5V 供电不等于 5V 模拟输出。未知传感器不能直接接 ADC。硬件接线必须先确认模拟输出及最大/最小电压、线序和共地；分压值由最坏电压、阻值公差及输入阻抗决定。USB-A PIO 端口不承担本版 PC HID 连接。首版为开发原型，未宣称工业级、游戏全兼容或硬件安全认证。
