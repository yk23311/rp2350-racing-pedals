# 可扩展接线底板 V0.1：设计评审稿

日期：2026-11-06。用户要求绘制方便接线、可扩展的 PCB；已选择沿用现有微雪 RP2350-USB-A，预留震动与直驱伺服力反馈，电机/伺服驱动器尚未选型。本稿用于确认设计范围，尚未绘制/验证电路与布线，不是生产文件。

## 推荐架构与取舍

采用“RP2350-USB-A 插接底板 + 可更换力反馈接口子板”。底板不承载伺服电机功率，不集成逆变桥、母线电源或市电电路。外部伺服驱动器负责电流/扭矩闭环和电机编码器；接口子板按选定驱动器实现通信与隔离。

相比重做 RP2350 独立主板，这能复用现有 USB、电源、下载与已工作的踏板固件。相比把某种 PWM/DIR 驱动接口焊死在底板，子板允许以后选择 CAN、RS485、模拟扭矩或其他接口；这些接口并不互相兼容，不能承诺一个接插件直接兼容所有伺服。

## 基板接口

建议 100×80mm 内、双层、1.6mm FR-4、四个 M3 固定孔。实际外形在连接器布局后确定；暂无机壳限位要求。开发板用两条 1×9、2.54mm 排母插接，USB Type-C 与 USB-A 保留插拔空间。

| 功能 | V0.1 设计范围 |
|---|---|
| 油门/刹车 | 螺丝端子分别引出 5V/GND/OUT，保留 GP26/GP27；定义丝印线序，不按线颜色推断 |
| 第三踏板 | GP28，独立同规格信号调理 |
| 辅助模拟量 | GP29，预留第四路模拟输入 |
| 信号调理 | 每路固定电阻分压 + RC，初选 10k/10k、100nF，延续已有试接方案；接口按 0–5V 模拟输出设计，不能用于任意 PWM/数字传感器 |
| I²C | GP0/GP1，3.3V 电平；小屏/传感器扩展口，地址与上拉预算统一管理 |
| 按键 | I²C GPIO 扩展器，目标 16 路，接插件引出，避免占满 MCU 直连引脚 |
| 旋转编码器 | GP2/GP3 的 A/B 输入，首版按低压逻辑接口；RS422/其他编码器需对应接口子板，不能直接混接 |
| 震动控制 | I²C PWM 扩展器产生两路控制信号，接外部马达驱动；仅信号，不向马达供电。预留额外 PWM 通道供后续扩展 |
| 直驱力反馈扩展槽 | SPI0（GP4/5/6/7）、GP8 控制使能、GP9 中断/故障、3.3V/GND；供接口子板使用，不直接接电机，不预先假定 CAN 或 PWM 协议 |
| 模式按键 | GP10 预留；现有固件默认 GP14 未由模块排针引出，需要后续适配 |

芯片候选为 PCA9555 类 16 位 I²C GPIO 扩展器和 PCA9685 类 PWM 扩展器；在原理图阶段核对数据手册、复位输出状态、封装和可采购型号后锁定 BOM。板上默认无伺服使能，输出带明确的默认关断电平。

所有扩展信号以 3.3V 为基准。传感器 5V 与逻辑 3.3V 分开标注，传感器供电增加支路保护和去耦。整板 USB 功耗仍须结合实际传感器、接收器和屏幕核对；主板 GPIO/USB 电源不承担电机电流。

## 直驱伺服边界

应选择支持合适扭矩/电流指令与位置反馈的伺服驱动器；常见脉冲位置控制不能自动等价为方向盘扭矩控制。实际 CAN/RS485/模拟量/编码器电路在电机和驱动器选型后完成对应子板。

硬件急停应按驱动器手册接其 STO/可靠禁用链，独立于 GUI 和 MCU。普通 GPIO 使能不是安全认证的 STO；底板不会把一个普通开关口宣称为完整安全急停。隔离、故障反馈、上电禁用、通信丢失卸扭矩与最大扭矩限制属于后续驱动子板及固件的联合要求。

当前 0.5.0 只有 XInput 双马达震动与踏板/手柄桥接；不具备方向盘 HID PID 力反馈效果处理和直驱扭矩控制。预留连接器不代表新增功能已可在游戏中工作。本次不改现有固件、USB 识别方式或游戏配置。

## 已核实机械与引脚

官方尺寸图给出模块 33.00×17.50mm；两排焊孔中心距可由 17.50−2×1.13 得到 15.24mm，纵向 2.54mm，首孔中心距板顶 2.88mm。顶部为 Type-C、底部为 USB-A；面向元件面，右列从上到下 GP0..GP8，左列从上到下 VSYS(5V)、GND、3V3、GP29、GP28、GP27、GP26、GP10、GP9。

P1 逻辑编号 1..11=GP0..GP10，12..15=GP26..GP29，16=3V3，17=GND，18=VSYS。GP12/13 属于板载 USB-A，GP16 为 RGB；GP14 不在 P1。自定义模块封装须按逻辑号与实物坐标映射，不能直接套用 Pico 排针封装。

## 交付与检验

确认本稿后，使用 KiCad 绘制可编辑原理图/PCB、自定义模块封装、BOM、接线表和预览图，并记录设计检查及交接步骤。系统当前未安装 KiCad；将先准备真实 CAD 引擎，不用绘图效果图代替电气与布线验证。

可投样板的底板制造文件要经过原理图 ERC、PCB DRC、网表一致性、孔位/USB插接空间与电源/默认输出审查。首版仍属于待实物测试的工程样板。伺服接口子板由于驱动器未选型，本次仅给扩展槽接口定义，不生成未经选型的驱动功率/安全电路。
